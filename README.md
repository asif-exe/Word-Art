# NEON//FORM

NEON//FORM is a small web project that turns a photo into a portrait made from text. Enter a name or short message, pick a style, and watch the words gradually form the image.

You can choose between three looks: Neon Cyberpunk, True Photo Colour, and Gallery Editorial. The finished portrait can be saved as a PNG, or exported as a 20-second WebM video in a vertical 9:16 format.

## How to Run

Keep `index.html`, `style.css`, and `script.js` in the same folder, then open `index.html` in Chrome or Edge. Upload a JPG, PNG, or WebP image (up to 25 MB), enter your text, choose a style, and click **Create artwork**.

If you're using the uploaded files, rename `index(6).html`, `style(3).css`, and `script(3).js` to the names above first.

## Built With

HTML, CSS, and vanilla JavaScript, using the Canvas and MediaRecorder APIs. No server or installation is needed. Photos are processed in your browser rather than uploaded by the page.
